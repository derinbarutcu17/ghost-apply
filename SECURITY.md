# Security policy

Ghost Apply is local-first and deliberately does not store passwords, cookies,
MFA codes, CAPTCHA answers, or ATS session tokens. Do not paste private
candidate data, browser traces, or real application receipts into a public
issue or pull request.

Report a vulnerability privately to the repository maintainers rather than
opening a public issue. Include the affected version, a minimal reproduction,
and the impact. Do not include real personal data.

The project does not bypass authentication, CAPTCHA, rate limits, or portal
restrictions. Live submission is opt-in and must remain visible to the user.
